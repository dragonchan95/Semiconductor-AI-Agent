1장 · 10초 · 반도체 검사 모델 실험·관리 Agent
안녕하세요. SKALA 광주 2반 G045 김용찬입니다. 반도체 검사 모델을 처음 비교할 때부터 성능 점검과 재학습까지 돕는 Agent를 만들었습니다.

2장 · 15초 · 모델을 고를 때와 성능이 떨어졌을 때를 돕습니다
엔지니어는 새 모델을 고를 때 전처리와 학습 제품 범위, 모델 조합을 반복해서 비교합니다. 이후 데이터가 바뀌면 기존 모델이 여전히 잘 찾는지도 확인해야 합니다. 이 두 업무를 계획, 승인, 실행, 결과 설명으로 연결했습니다.

3장 · 20초 · 불량을 놓치지 않되, 정상 오판도 제한합니다
불량을 실제로 얼마나 찾았는지가 Recall입니다. 모두 불량이라고 해도 Recall은 높아지므로 정상을 불량으로 잘못 보는 비율도 제한합니다. 이번 교육용 목표는 검출률 구십 퍼센트 이상, 정상 오판 십오 퍼센트 이하입니다. 그 안에서 Recall을 먼저, 동률이면 F1을 비교합니다.

4장 · 10초 · ① 검사 데이터를 선택합니다
제품 A부터 D의 합성 센서 천이백팔십 건을 선택합니다. 실제 공장 데이터는 아닙니다. 내 센서 CSV나 검사 이미지 ZIP을 등록하는 기능도 있습니다.

5장 · 20초 · ② 비교 범위를 확인하고 승인합니다
Agent가 결측과 불균형을 확인하고 모델별 전처리 이유를 보여 줍니다. 예를 들어 SVM은 센서 값의 크기 차이에 민감해 Scaling을 사용합니다. 전처리는 Train에만 맞추고 학습, 후보 선택, 마지막 확인을 육 대 이 대 이로 고정했습니다. 엔지니어가 계획을 승인하면 실행합니다.

6장 · 25초 · ③ 제품 묶음 선택: ABC 공통 모델 + D 전용 모델
첫 실험은 CatBoost를 고정하고 제품 담당 그룹 열다섯 개를 비교합니다. Validation에서는 ABC를 함께, D는 따로 학습한 구성이 선택됐습니다. 하지만 Test 검출률은 칠십팔 점 일 퍼센트로 목표에 미달했습니다. 선택 후보와 현장 적용 가능성을 구분해 보류를 표시합니다.

7장 · 25초 · ④ 선택 비율: CatBoost 90% + LightGBM 10%
두 번째 실험은 학습 제품 ABCD를 고정하고 세 모델의 혼합 비율을 비교합니다. 다섯 퍼센트 간격과 균등 비율을 포함한 이백서른두 개 중 CatBoost 구십, LightGBM 십 퍼센트를 골랐습니다. Validation에서 검출률을 유지하면서 정상 오판과 F1이 개선됐습니다.

8장 · 25초 · ⑤ 같은 검출률을 유지하며 정상 오판을 줄였습니다
선택한 비율을 고정한 뒤 같은 Test에서 확인했습니다. 단일 모델과 혼합 모델 모두 불량 서른두 개 중 서른 개를 찾았습니다. 정상 오판은 스물한 개에서 열아홉 개로 줄었습니다. 합성 데이터의 탐색 결과라 새로운 독립 데이터 검증이 필요합니다.

9장 · 25초 · ⑥ 새 정답 데이터로 기존 모델을 점검합니다
사용 중인 모델에는 새 정답 데이터를 선택해 그대로 점검하는 기능을 제공합니다. 이 별도 합성 배치는 결함 발생 규칙을 바꾼 사례입니다. 제품별 검출률과 정상 오판을 확인하고 재학습 비교를 제안합니다. 불량 표본이 부족하면 판단을 보류하며 바로 학습하지 않습니다.

10장 · 35초 · ⑦ 승인 후 재학습하고, 같은 Test에서 비교합니다
계획을 승인하면 같은 CatBoost로 재학습합니다. 새 배치의 같은 Test에서 불량 발견이 백육십일곱 개 중 마흔세 개에서 백쉰세 개로 늘었고, 정상 오판은 아흔여섯 개에서 일흔아홉 개로 줄었습니다. 후보와 버전 기록을 저장하며 운영 모델은 자동 교체하지 않습니다.

11장 · 25초 · 역할을 나누고, 실행과 답변을 검증했습니다
LangGraph로 점검, 검색, 계획 역할을 연결했습니다. RAG는 BGE-M3와 FAISS로 근거를 찾아 Qwen에 전달하며, MCP는 조회와 계획 도구를 제공합니다. 실제 학습과 지표는 코드가 계산합니다. LangSmith 실행 추적과 테스트 쉰두 개를 확인했고, LLM 설명 검사도 실패 사례와 함께 기록했습니다.

12장 · 25초 · 선택 근거와 검증 실패를 함께 남깁니다
모델을 고르는 실험과 이후의 성능 점검, 승인 후 재학습을 한 흐름으로 연결했습니다. 높은 Validation 점수가 미래 성능을 보장하지 않는다는 점을 배웠습니다. 합성 데이터와 작은 표본이 한계이며, 현장 기준과 독립 기간 검증 후 상시 감시와 운영 연동을 확장하겠습니다. 감사합니다.

질문 대비:
- 현재 관리 기능은 정답이 있는 새 배치의 성능 점검이며 상시 감시는 미구현입니다.
- 90%·15%·불량20개·Recall 10%p 하락은 교육용 기준입니다.
- 재학습 사례는 새 합성 배치이며 그룹·앙상블 사례의 Test와 다릅니다.
- 재학습은 같은 알고리즘을 새 Train으로 다시 학습한 것이며, 과거 파일을 자동 병합하지 않습니다.
- 운영 모델은 자동 교체하지 않으며 후보·버전·승인·비교 결과만 저장합니다.
