1장 · 8초 · 반도체 검사 모델 실험·관리 Agent
안녕하세요. SKALA 광주 2반 G045 김용찬입니다. 반도체 검사 모델을 비교하고, 성능 점검과 재학습까지 돕는 Agent를 만들었습니다.

2장 · 15초 · 입력 데이터에 맞는 모델을 비교합니다
데이터 종류에 맞는 모델과 전처리를 제안하고, 승인 후 비교하는 Agent입니다. 현재 센서 열두 종류와 이미지 세 종류를 구현했습니다. 시계열과 장비 로그는 전용 데이터와 학습 연결이 필요한 확장 범위입니다.

3장 · 20초 · 불량을 놓치지 않으면서, 정상도 지킵니다
불량을 정상으로 놓치면 다음 공정이나 고객에게 넘어갈 위험이 있어 Recall을 우선 봅니다. 하지만 모두 불량이라고 하면 정상 제품까지 전부 잘못 잡습니다. 그래서 정상 오판을 제한한 안에서 Recall을 최대화하고, 같으면 F1을 비교합니다. 구십 퍼센트와 십오 퍼센트는 교육용 목표입니다.

4장 · 8초 · ① 검사 데이터를 선택합니다
오늘 본문은 합성 센서 데이터입니다. 퍼센트는 실제 학습해 측정한 값입니다. 실제 공개 SECOM 자료도 별도로 실험했습니다.

5장 · 18초 · ② 비교 범위를 확인하고 승인합니다
빈값 처리와 Scaling처럼 학습 전 준비도 설명합니다. 데이터의 육십 퍼센트로 학습하고, 이십 퍼센트로 후보를 고릅니다. 마지막 이십 퍼센트는 최종 시험용으로 남깁니다. 엔지니어가 계획을 승인하면 실행합니다.

6장 · 13초 · ③ 개별 모델 비교와 선택 근거
개별 센서 모델의 실제 비교입니다. F1은 AdaBoost가 더 높지만 Recall은 CatBoost가 높습니다. 이번에는 정상 오판 한도 안에서 Recall을 먼저 보는 기준이라 CatBoost를 골랐습니다.

7장 · 20초 · ④ 제품 묶음 비교: ABC는 함께, D는 따로 학습
다음은 CatBoost를 고정하고 제품을 합칠지 나눌지 비교한 별도 실험입니다. 후보 선택용 데이터에서는 ABC를 함께, D는 따로 학습한 구성이 좋았습니다. 하지만 마지막 시험의 검출률은 칠십팔 점 일 퍼센트로 목표에 미달해 적용을 보류했습니다.

8장 · 18초 · ⑤ 선택 비율: CatBoost 90% + LightGBM 10%
이번에는 제품 ABCD를 합쳐 학습한 세 모델의 예측 점수를 섞었습니다. 비율 이백서른두 개를 비교해 후보 선택용 데이터에서 CatBoost 구십, LightGBM 십 퍼센트를 골랐습니다. 앞의 제품 그룹 실험과는 별도 비교입니다.

9장 · 15초 · ⑥ 같은 검출률을 유지하며 정상 오판을 줄였습니다
마지막 시험에서는 단일 모델과 혼합 모델 모두 불량 서른두 개 중 서른 개를 찾았습니다. 정상 오판은 스물한 개에서 열아홉 개로 줄었습니다. 같은 검출률을 유지하면서 정상도 덜 잘못 잡았습니다.

10장 · 15초 · ⑦ 새 정답 데이터로 기존 모델을 점검합니다
만든 모델이 새 데이터에서도 잘 찾는지 점검합니다. 정상·불량이 표시된 별도 합성 데이터에서 성능이 떨어지자 재학습 비교를 제안했습니다. 표본이 부족하면 판단을 보류합니다.

11장 · 20초 · ⑧ 승인 후 재학습하고, 같은 Test에서 비교합니다
승인 후 같은 CatBoost로 다시 학습했습니다. 같은 마지막 시험에서 불량 발견이 백육십일곱 개 중 마흔세 개에서 백쉰세 개로 늘었습니다. 정상 오판은 아흔여섯 개에서 일흔아홉 개로 줄었습니다. 운영 모델을 자동 교체하지는 않습니다.

12장 · 15초 · 이미지 모델도 별도로 학습해 비교했습니다
이미지는 축소 ResNet, VGGNet, Autoencoder를 실제로 비교했습니다. 단순 합성 패턴이라 후보 선택 점수는 같습니다. EfficientNet은 아직 학습하지 않은 추가 후보로 구분했습니다.

13장 · 15초 · 공식 문서에서 비교 후보를 추가할 수 있습니다
새 후보를 찾을 때는 공식 문서를 검색해 관련 내용을 언어모델에 전달하는 RAG를 사용합니다. ExtraTrees와 GaussianNB를 제안하고, 승인 후 기존 후보와 비교합니다.

14장 · 12초 · 역할을 나누고, 실행과 답변을 검증했습니다
설명과 계획은 언어모델이 돕고, 학습과 숫자 계산은 코드가 담당합니다. 역할 분리, 근거 검색, 도구 연결과 실행 추적을 적용했습니다.

15장 · 20초 · LLM-as-a-Judge: 설명이 맞는지 LLM이 검사합니다
언어모델 설명도 틀릴 수 있어 실제 결과와 함께 검사했습니다. 여덟 예제 중 여섯 개는 맞게 판단했지만 두 개는 틀렸습니다. 실제 이십칠 개를 삼십 개라고 한 오류도 놓쳐서 보조 검사로 사용합니다.

16장 · 12초 · 공개 데이터에서도 확인하고, 실패를 기록했습니다
실제 공개 SECOM 데이터도 시험했지만 불량 스물세 개 중 다섯 개를 찾아 목표에 미달했습니다. 합성 데이터의 좋은 결과가 실제 생산 성능을 보장하지 않으므로, 실패도 기록하고 다시 검증해야 합니다.

17장 · 6초 · 과제 기술 요소와 실제 구현 위치
마지막은 과제 기술 요소와 실제 구현 위치입니다. 이상 발표를 마치겠습니다. 감사합니다.

질문 대비 (발표 본문에서는 읽지 않습니다):
- 데이터: 본문 센서12종, 별도 이미지3종. EfficientNet·GAN·시계열·장비 로그 모델은 미구현 확장 후보입니다.
- LSTM은 시계열과 텍스트 양쪽에 쓸 수 있습니다. 현재는 연속 입력 창·예측 목표와 로그·정답 데이터가 준비되지 않았습니다.
- Autoencoder는 현재 이미지 복원 오차로 이상을 점수화합니다. 시계열용 Autoencoder는 별도 미구현입니다.
- Agent의 설명용 Qwen은 사용합니다. BERT/GPT 장비 로그 분류 실험은 구현하지 않았습니다.
- Recall = 실제 불량 중 찾은 비율. 정상 오판률 = 실제 정상 중 불량으로 잘못 잡은 비율.
- Precision = 불량이라고 잡은 것 중 진짜 불량의 비율. F1은 Precision과 Recall의 조화평균.
- 불량을 정상으로 놓침은 FN, 정상을 불량으로 오판은 FP입니다.
- 앙상블: 정상 오판률 한도 내 Recall 최대, 동률이면 F1. Recall90%는 목표 달성 여부에도 사용합니다.
- 제품 그룹: 제품별 정상 오판 한도·검출 목표를 확인한 뒤 전체 Recall·F1을 비교합니다.
- 초기 개별 모델·재학습: 두 목표 충족 여부, Recall, 정상 오판률 순으로 선택하고 F1도 표시합니다.
- ‘Recall90% 이상 중 F1 최대’는 다른 정책입니다.6장 표에서는 AdaBoost를 고를 수 있지만 현재 정책으로 바꾸지는 않았습니다.
- 예:6장 CatBoost는 Recall100%·F1 0.808·정상 오판9.3%, AdaBoost는 Recall97.6%·F1 0.854·정상 오판6.1%입니다. 둘 다 목표를 넘지만 이번 기준은 Recall을 먼저 봅니다.
- 여러 지표의 점수를 더하거나 금액으로 바꾸지 않습니다. 90%·15%는 교육용 기준입니다.
- 이미지 표는 같은Validation114건(불량19·정상95)에서 전처리2조건 중 각 모델의 최선입니다. 단순 합성 이미지이며 실제 회사 우위를 입증하지 못합니다.
- 선택 Autoencoder는 Test14/15개 검출·정상 오판0/105개입니다. 불량 표본20개 기준 미달로 적용 판단을 보류했습니다.
- 이미지 모델과 센서 모델은 데이터가 달라 하나의 성능 순위로 합치지 않습니다.
- Train=학습용, Validation=후보 선택용, Test=마지막 확인용. 목표6:2:2를 고정했습니다.
- 정답이 있는 새 배치를 점검하고 승인 후 재학습합니다. 상시 감시·자동 운영 교체는 향후 범위입니다.
