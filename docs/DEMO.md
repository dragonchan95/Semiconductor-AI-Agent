# 발표와 화면 시연

[발표 대본 TXT](발표대본_G045.txt)을 사용합니다. 1~9장은 약5분,10~11장은 기술 질의응답용 부록입니다.

1. `bash start.sh`로 실행하고 http://localhost:8700 을 엽니다.
2. 연습용 공정 데이터, 완료된 예시 결과 바로 보기를 선택합니다.
3. 추가 발견28개와 정상 추가검사97.0개를 설명합니다. N1000·불량10%의 가정 환산입니다.
4. 재작업 가정을 켜고91.20%와91.76%,0.56%p를 확인합니다. 실제 제조 수율 실측이라고 표현하지 않습니다.
5. 아래의 성능 저하 데모를 준비하고 기존 모델 성능을 점검합니다.
6. 통합·제품별 비교 계획 자동 생성. 계획 생성만으로 학습하지 않습니다.
7. 검토 후 승인하면 공통1개·전용4개 후보를 학습합니다.
8. 동일 제품 validation 비교와 최종 보류 판단을 확인합니다.

새 설치에는 저장된 실행 이력이 없습니다. 예제 데이터 준비 후 계획을 생성·승인하면 첫 결과가 생깁니다.
재현용 scripts/evaluate.py, scripts/evaluate_management.py는 명시적으로 표시한 자동 테스트 승인자를 사용합니다. 현장 승인 실적이 아닙니다.

질문 대응: app/planner.py는 데이터 형식별 후보와 근거, app/store.py는 단일 승인과 hash, app/experiments.py는 공정 학습, app/images.py는 이미지 학습, app/monitoring.py는 성능 저하와 학습 방식 비교, app/impact.py는 가정 계산입니다.
