# 5분 발표 흐름

SKALA 광주2반 · G045 김용찬. 1~16장 설명,17장은 기술 대응표와 마무리입니다. 발화 목표250초 + 전환20초 + 여유30초이며 전체 리허설 실측은 아닙니다. 표의 모든 행을 읽지 않습니다.

| 장 | 내용 | 발화 목표 |
|---|---|---|
| 1 | 반도체 검사 모델 실험·관리 Agent | 8초 |
| 2 | 입력 데이터에 맞는 모델을 비교합니다 | 15초 |
| 3 | 불량을 놓치지 않으면서, 정상도 지킵니다 | 20초 |
| 4 | ① 검사 데이터를 선택합니다 | 8초 |
| 5 | ② 비교 범위를 확인하고 승인합니다 | 18초 |
| 6 | ③ 개별 모델 비교와 선택 근거 | 13초 |
| 7 | ④ 제품 묶음 비교: ABC는 함께, D는 따로 학습 | 20초 |
| 8 | ⑤ 선택 비율: CatBoost 90% + LightGBM 10% | 18초 |
| 9 | ⑥ 같은 검출률을 유지하며 정상 오판을 줄였습니다 | 15초 |
| 10 | ⑦ 새 정답 데이터로 기존 모델을 점검합니다 | 15초 |
| 11 | ⑧ 승인 후 재학습하고, 같은 Test에서 비교합니다 | 20초 |
| 12 | 이미지 모델도 별도로 학습해 비교했습니다 | 15초 |
| 13 | 공식 문서에서 비교 후보를 추가할 수 있습니다 | 15초 |
| 14 | 역할을 나누고, 실행과 답변을 검증했습니다 | 12초 |
| 15 | LLM-as-a-Judge: 설명이 맞는지 LLM이 검사합니다 | 20초 |
| 16 | 공개 데이터에서도 확인하고, 실패를 기록했습니다 | 12초 |
| 17 | 과제 기술 요소와 실제 구현 위치 | 6초 |

개별 모델 비교를 제품 묶음·앙상블보다 앞에 배치했습니다. 제품 묶음과 앙상블은 조건이 다른 별도 실험입니다. 본문은 합성 센서 실측이며 실제 공개 SECOM·합성 이미지·변화 합성 배치는 별도 실험으로 설명합니다.
