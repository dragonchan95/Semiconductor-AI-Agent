# 5분 시연

1. http://localhost:8700에서 연습용 공정 데이터와 완료된 예시 결과를 선택합니다.
2. SVM 선택 이유와 학습 중앙값·표준화 설명을 읽습니다. 적용 보류도 함께 설명합니다.
3. 1,000개·불량10% 가정에서 추가 발견36개, 정상 추가검사134.7개 증가를 비교합니다.
4. 재작업20%를 가정하면 양품7.2개 추가 회수, 재작업 후 양품 비율0.72%p 증가입니다. 실제 제조 수율 실측이 아닙니다.
5. 새 데이터의 성능 저하를 점검하고 공통·전용 비교 계획을 만듭니다. 계획만 만들 때 학습하지 않음을 보여줍니다.
6. 승인 후 후보를 학습하고 A공통·C전용 권고, B·D보류의 기존 예시를 확인합니다.
7. 시간이 있으면 비교 계획을 생성하여 데이터·전처리 이유와 모델12종, Agent별 출처·fallback 상태를 보여줍니다.

LLM 사용: Ollama의 qwen3.5:2b와 qwen3-embedding:0.6b를 준비하고 `SEMI_LLM_ENABLED=1 bash start.sh`로 실행합니다. 유료 API가 필요하지 않습니다. 연결 실패는 규칙·TF-IDF 모드로 표시합니다.
