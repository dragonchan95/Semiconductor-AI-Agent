# 서로 다른 모델의 예측 확률을 섞는 기능

이번 기능은 Random Forest·부스팅 모델 자체를 사용하는 것에서 더 나아가, **서로 다른 알고리즘이 낸 불량 확률을 비율대로 합치는 weighted soft voting**입니다.
예를 들어 CatBoost가0.8, LightGBM이0.4라고 예측하면90:10 조합의 불량 점수는 `0.9×0.8 + 0.1×0.4 = 0.76`입니다.
이는 계산 예시이며 실제 측정 샘플은 아닙니다.

## 무엇을 기준으로 고르나요?

불량 미검출을 줄이는 목적에 맞춰 **정상 오판률 한도 이하 → Validation Recall 최대 → 동률 F1 최대** 순서로 고릅니다.
F1까지 같으면 정상 오판이 적고 구성 모델 수가 적은 쪽을 고릅니다. 똑같은 성능이면 단일 모델을 유지할 수 있습니다.
Recall90%는 달성 여부를 확인하는 시연 목표이며, 정상 오판률15%도 회사의 공통 기준이 아닌 설정값입니다.
F1은 Precision과 Recall의 조화평균입니다. F1·Precision·정상 오판률도 결과에 함께 표시합니다.

1. 같은 학습 제품 범위의 기존 Validation 성능에서 서로 다른 상위 알고리즘 최대3개를 고릅니다.
2. 구성 모델·설정·데이터 hash·분할·비율 간격·선택 규칙을 계획에 저장하고 승인받습니다.
3. 전처리와 모델을 Train에서만 적합합니다. Validation 행은 모든 모델에서 동일합니다.
4. 세 모델의 합계100% 비율을5% 간격으로 빠짐없이 비교합니다.231개에 균등33⅓%를 더해232개입니다. 단일 모델100%도 포함합니다.
5. 각 비율의 판정 기준도 Validation 예측 점수의 모든 서로 다른 경계에서 비교합니다.
6. 비율과 판정 기준을 확정한 뒤, 최선 단일 모델과 선택 조합만 같은 Test에서 확인합니다.

## 실제 측정한 예제

구성 후보는 CatBoost·HistGradientBoosting·LightGBM입니다. 모두 A+B+C+D Train768건을 사용합니다.
Validation256건, Test256건으로 같은 생산 묶음이 경계를 넘지 않도록 분리했습니다.
선택 비율은 **CatBoost90% · HistGradientBoosting0% · LightGBM10%**입니다.

| Validation | Recall | 정상 오판 | F1 |
|---|---:|---:|---:|
| 최선 단일 CatBoost | 100% | 20/214 | 0.808 |
| 균등 혼합 | 100% | 22/214 | 0.792 |
| 선택90:0:10 | 100% | 19/214 | 0.816 |

검출률이 같았으므로 F1이 더 높은 비율을 선택했습니다. 이 실행에서는 같은 우선 성능의 비율이1개였습니다.

| 비율 선택 후 같은 Test | 최선 단일 CatBoost | 선택90:0:10 |
|---|---:|---:|
| 불량 발견 | 30/32 | 30/32 |
| 정상 오판 | 21/224 | 19/224 |
| Recall | 93.75% | 93.75% |
| Precision | 58.82% | 61.22% |
| F1 | 0.723 | 0.741 |

기존 제품 조합 탐색의 CatBoost A+B+C(발견27/32)와는 별도 실험입니다.
여기서는 같은 전체 제품 Train의 단일 CatBoost와 혼합 후보를 비교하며, 비율과 판정 기준을 함께 선택한 절차의 결과입니다.

## 최적이라고 말할 수 있는 범위

**승인한 구성 모델·비율 간격·Validation 안에서 정한 기준으로 가장 좋은 결과**라고 말할 수 있습니다.
모든 알고리즘, 모든 연속 비율, 미래 공정에서의 전역 최적이나 양산 승인을 뜻하지 않습니다.
비율과 구성 후보를 같은 Validation에서 반복 선택했으며, 프로젝트에서 이미 확인했던 Test를 추가 탐색에 재사용했습니다.
최종 현장 판단에는 새로운 독립 기간 데이터가 필요합니다. 모델 확률을 별도로 보정하지 않았으므로 확률 척도 차이도 한계입니다.
비율은 예측 점수를 섞는 비중이며 센서 중요도나 인과적 공헌도가 아닙니다.

## 실행과 근거

앱에서 완료된 개별 모델 결과를 열고 **앙상블 비율 비교 계획 → 계획 승인·학습 시작**을 누릅니다.
기존 결과는 **저장된 앙상블 결과 보기**에서 확인하고, 전체232개 비율의 점수·판정값은 CSV로 받을 수 있습니다.
승인 해시가 틀리거나 승인하지 않은 실행, 중복 승인은 차단합니다. 구성 모델과 선택 비율은 `champion.joblib`에 저장해 재사용합니다.
외부 모델 탐색과 이미지용 앙상블은 별도 기능이며 현재 혼합은 센서 이진 분류를 지원합니다.
