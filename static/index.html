불량을 더 찾으면,
현장에 얼마나 도움이 될까요?

더 찾아낸 불량과 정상 제품의 추가 검사 부담을 함께 비교합니다.
새 데이터에서 성능이 떨어지면 통합·제품별 재학습 방식을 비교합니다.

데이터 선택하고 시작하기

공개·합성 데이터로 만든 교육용 프로그램입니다. 모델 학습은 엔지니어 승인 후 실행합니다.

5

새 데이터가 들어오면 재학습이 필요할까요?

현재 공정 모델로 새 데이터를 점검합니다. 불량 발견 비율이 10%p 넘게 떨어지거나 검사 부담 기준을 넘으면 재학습을 제안합니다.

이번 기능은 라벨이 있는 공정 CSV를 지원합니다. 통합·제품별 학습은 승인 후 실행합니다. 같은 제품 평가에서 학습 방식을 비교하고 후보 버전을 저장합니다. 운영 중인 장비나 모델을 자동 교체하지 않습니다.
