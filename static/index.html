부가 기능 (발표 범위 밖): 기존 모델 점검 · 재학습
5

상황 2 · 같은 제품에서 기존 모델의 성능이 떨어졌습니다

기존 모델을 그대로 두고 새 정상·불량 정답 데이터로 점검합니다. 같은 제품에서 목표에 못 미치면 재학습 비교를 제안합니다.

판정 정답이 없는 새 데이터는 검출률을 계산할 수 없습니다. 재학습 계획도 승인받아 실행하며, 운영 모델은 자동 교체하지 않습니다.
